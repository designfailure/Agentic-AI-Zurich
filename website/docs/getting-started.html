Getting Started with MCP Scheme Ontology

Welcome to the MCP Scheme Ontology! This guide will help you get started with installing, configuring, and using the semantic inference framework.

📦 Installation

Prerequisites

  • Node.js 18.x or higher
  • npm or yarn package manager
  • Basic knowledge of JSON and TypeScript

Install from NPM

npm install mcp-scheme-ontology

Clone from Repository

git clone https://github.com/designfailure/Agentic-AI-Zurich.git
cd Agentic-AI-Zurich
npm install

🚀 Quick Start

1. Initialize the Inference Engine

import { SemanticInferenceEngine } from 'mcp-scheme-ontology';

// Initialize the engine
const engine = new SemanticInferenceEngine({
  configPath: './ontology/semantic-inference-engine.json',
  componentsPath: './components',
  rulesPath: './inference-rules'
});

await engine.initialize();

2. Register Components

// Load and register your components
await engine.loadComponentsFromDirectory('./components');

// Or register a single component
const myComponent = {
  id: 'my-component',
  type: 'source-module',
  apiStructure: { /* ... */ },
  semanticContext: {
    domain: 'my-domain',
    intents: ['my-intent'],
    keywords: ['keyword1', 'keyword2']
  }
};

engine.registerComponent(myComponent);

3. Make an Inference Request

// Create an inference request
const request = {
  intent: 'Find customer orders',
  context: {
    user: 'analyst@company.com'
  },
  parameters: {
    customerName: 'John Doe'
  }
};

// Get inference result
const result = await engine.infer(request);

console.log('Selected Component:', result.selectedComponent.id);
console.log('Confidence:', result.confidence);
console.log('Reasoning:', result.reasoning);

4. Execute the Plan

// Execute the inference result
const response = await engine.execute(result.executionPlan);

console.log('Result:', response);
💡 Tip: The inference engine automatically caches results for improved performance. You can configure caching behavior in the engine configuration.

🔧 Configuration

Engine Configuration

The inference engine can be configured using a JSON file. Here's an example: 

{
  "enableCaching": true,
  "cacheTTL": 3600,
  "enableLogging": true,
  "logLevel": "info",
  "maxInferenceDepth": 5,
  "parallelInference": true,
  "timeout": {
    "inferenceTimeout": 5000,
    "componentTimeout": 30000
  }
}

❓ Common Issues

Component Not Found

Make sure your component is properly registered and the ID matches the one referenced in your inference rules.

Low Confidence Scores

Improve your semantic context by adding more intents, keywords, and concepts to your components. Also ensure your inference rules have appropriate thresholds.

Performance Issues

Enable caching, reduce the number of parallel rules, or adjust the maxInferenceDepth configuration.
