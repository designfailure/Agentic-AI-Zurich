Examples

See the semantic inference engine in action

Request

{
  "intent": "Find all orders for customer John Doe",
  "context": {
    "user": "analyst@company.com"
  }
}

Inference Result

Selected Component: database-query-component
Confidence: 92%
Dataset: customer-database
Tools: sql-generator → query-optimizer
Reasoning: Keywords match customer database domain with high intent overlap

Request

{
  "intent": "Analyze sentiment of customer reviews",
  "parameters": {
    "text": "The product is amazing!"
  }
}

Inference Result

Selected Component: nlp-processing-component
Confidence: 91%
Tool: sentiment-analyzer
Reasoning: Sentiment analysis intent matches NLP component capabilities

Request

{
  "intent": "Find similar documents",
  "context": {
    "query": "machine learning in healthcare"
  }
}

Inference Result

Selected Component: nlp-processing-component
Confidence: 89%
Dataset: document-store (vector)
Tools: embedding-generator → semantic-search
Reasoning: Semantic search requires embeddings and vector database

Request

{
  "intent": "Extract entities and store in database",
  "context": {
    "documentIds": ["doc-001", "doc-002"]
  }
}

Inference Result

Execution Mode: Multi-stage Pipeline
Confidence: 82%
1 Retrieve Documents
2 Extract Entities
3 Store Results
Reasoning: Multi-stage operation requires NLP extraction + database storage
